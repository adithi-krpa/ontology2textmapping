This is one of the methods attempted in my formal project "Semantic Interoperability - Multimodal Machine Learning for Healthcare Applications"
to map textual medical reports to an ontology (knowledge graph). An ontology is structed representation of inter-related information.
Mapping new, unstructured medical reports (after appropriate processing, nlp and ner) to an existing medical ontology can be helpful in assimilating new medical information 
or relationships and for diagnostic purposes.
